# OpenPonk: Finite-State Machines

[![Nightly](https://github.com/OpenPonk/fsm-editor/actions/workflows/nightly.yml/badge.svg)](https://github.com/OpenPonk/fsm-editor/actions/workflows/nightly.yml) [![Coverage Status](https://coveralls.io/repos/github/OpenPonk/fsm-editor/badge.svg?branch=master)](https://coveralls.io/github/OpenPonk/fsm-editor?branch=master)

Finite-State Machine (FSM) diagram editor, state simulator, and GraphML serializer for the [OpenPonk](https://openponk.org) modeling platform.

## Download

Download pre-built portable archives from [Releases](https://github.com/OpenPonk/fsm-editor/releases), or get the all-in-one build at [openponk.org/#download](https://openponk.org/#download).

## Installation

See [openponk.org/#direct-installation](https://openponk.org/#direct-installation) for the supported Pharo version.

```smalltalk
Metacello new
	baseline: 'OpenPonkFsmEditor';
	repository: 'github://OpenPonk/fsm-editor';
	load.
```
